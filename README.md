# BikeFit

Bike fit calculator: saddle height by LeMond and Hamley methods, frame size, handlebar width and fit symptom guide. Free.

## Features
- Twin comparison dials: LeMond vs Hamley with a recommended-start badge
- Frame-size recommender from inseam plus standover guidance
- Handlebar-width, setback and cockpit targets plus symptom diagnosis table
